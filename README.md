# Palm Coast Cover Forge

A GTA 6-style cover art maker: turn your photos and a caption into a multi-panel poster cover and export it as a PNG in 1080x1080, 1080x1350 and 1920x1080. Runs fully offline in desktop Chrome. Built for the make.fun bounty [Make GTA 6 Cover Art](https://make.fun/c/gta6-cover-art-01).
